# Inter font

`Inter-VariableFont_opsz,wght.ttf` is the unmodified Inter variable font from
the official Google Fonts repository.

- Upstream project: https://github.com/rsms/inter
- Distribution source: https://github.com/google/fonts/tree/main/ofl/inter
- License: SIL Open Font License 1.1 (see `OFL-Inter.txt`)

The font may be embedded and redistributed with Stumped! under the terms of
that license. Keep `OFL-Inter.txt` with packaged source and release materials.
